# 小丑牌（Balatro）小丑分布逆向分析

> 创建：2026-08-26 ｜ 用途：将领池 v1 设计参考（#D40 配套）
> 数据源：Balatro Wiki（balatrowiki.org / balatrogame.fandom.com），基座版本 150 张
> 方法：稀有度 × 效果类型双轴归类，对照本作将领体系找可迁移规律

## 1. 总量与稀有度结构

| 稀有度 | 数量 | 池占比 | 商店出现率 | 获取途径 |
|--------|------|--------|-----------|---------|
| 常见 Common | 61 | 40.7% | 70% | 商店/卡包 |
| 非常见 Uncommon | 64 | 42.7% | 25% | 商店/卡包 |
| 稀有 Rare | 20 | 13.3% | 5% | 商店/卡包 |
| 传说 Legendary | 5 | 3.3% | 不可购买 | 仅灵魂（Spectral 0.3%） |

**关键发现 ①：数量分布 ≠ 获取分布。** 出现率按稀有度档分配（70/25/5），档内均匀：

- 单张常见小丑出现率 ≈ 70%/61 ≈ **1.15%**
- 单张稀有小丑出现率 ≈ 5%/20 = **0.25%**
- **最稀有单卡仅为最普通单卡的 ~4.6 倍**——"稀有的是杠杆不是鸿沟"

**关键发现 ②：低两档占池 83%。** 日常供给的基础盘极大，稀有层薄但承担全部质变想象；传说层 5 张完全绕开商店（命运叙事，类似本作 #D40"专属层仅紫红"的强化版）。

## 2. 效果类型分布（效果轴）

| 类型 | 约数 | 池占比 | 代表 |
|------|------|--------|------|
| 条件触发（花色/点数/牌型） | 40+ | ~27% | Fibonacci、The Duo~Tribe、花色四兄弟 |
| 功能/复制/规则改变 | ~35 | ~23% | Blueprint（复制右侧）、Four Fingers（改规则）、DNA |
| 平铺 +Mult | ~17 | ~11% | Joker(+4)、Gros Michel(+15 带自毁) |
| X 倍率 | ~20 | ~13% | Baron(X1.5/王)、Cavendish(X3) |
| 成长型 | ~18 | ~12% | Ride the Bus、Vampire、Obelisk |
| 经济产金 | ~18 | ~12% | Golden Joker($4/轮)、To the Moon(利息) |
| 平铺 +Chips | ~10 | ~7% | Ice Cream(+100 衰减)、Stuntman(+250) |

**正交第二轴（触发轴）**：常驻 / 条件触发 / 成长 / 复制——同一效果轴可挂不同触发轴（如"成长"既有 +Chips 成长也有 X 成长），两轴组合出 150 张的多样性。

## 3. 稀有度 × 效果交叉规律（分层职责）

| 稀有度 | 效果职责 | 特征 |
|--------|---------|------|
| 常见 61 | 平铺数值 + 简单条件 | 无脑可用，卖掉不心疼；含少量衰减型制造节奏（Ice Cream/Popcorn） |
| 非常见 64 | 条件进阶 + 成长起步 + 经济主力 | 开始要求构筑配合（花色系、Fibonacci） |
| 稀有 20 | **X 倍率集中地** + 复制 + 规则改变 | 质变杠杆：Baron、Blueprint、Driver's License |
| 传说 5 | 唯一效果：无上限成长（Canio/Yorick）、规则豁免（Chicot 关 Boss）、复制（Perkeo） | 不进商店 = 命运级叙事 |

## 4. 对本作的映射与启示

### 4.1 池形对比

| | Balatro | 本作 v1（#D40） |
|--|---------|----------------|
| 池总量 | 150 | 34（单派系单英雄，合理） |
| 池形 | 金字塔（低两档 83%） | **头重脚轻**：白6/绿9/蓝7/紫7/红5（紫红占 35%） |
| 单卡获取差 | 4.6× | 若按掉落权重 1/2/4/8/16 直推：红单卡出现率 = 白单卡 **16×** |

**启示 A（待办）**：商店上架权重属内容设计未定（§8.8 🚧）。建议**学 Balatro 按稀有度档分配出现率、档内均匀**（如 白60/绿25/蓝10/紫4/红1），而非按单卡权重——避免"红将满地走、白将没人见"。掉落体系（#D23）保持权重制不变：**商店管供给曲线，掉落管奖励幻想**，两轨分离。

### 4.2 X 倍率轴：本作主动移除

Balatro 后期 = X 链复利（Blueprint 复制 Baron 等）；本作 #D11 线性叠加只加不乘、#D35 复利杠杆归禁术——**X 轴被整体砍掉是既定决策**。后果：本作后期强度杠杆改为①稀有度获取曲线（掉落驱动）②派系协同深度③牌型档位（#D33 家族修正 3/4/5 已是"温和的 X"）。逆向时不可照抄 X 分布，但**"复制"作为想象力来源值得保留候选**——将领层可考虑 1~2 张"复制相邻将领被动"的专属红/禁术（Blueprint 位），属线性体系内安全的强效果。

### 4.3 结构对应关系

| Balatro | 本作对应 | 状态 |
|---------|---------|------|
| 常见/非常见（基础盘 83%） | 白绿将（功能位） | 池形需参考启示 A 调供给 |
| 稀有（X/复制集中） | 紫将 | 对齐 |
| 传说（Soul 限定不可购） | 专属层仅紫红（#D40） | 已对齐；专属红将承担"命运叙事" |
| 经济类 12% | 统御类 18%（6/34） | 略高，注意生息红线（被动金币被否，只做一次性/条件经济） |
| 成长型 12% | 将领无成长（线性叠加）；成长挂在军备升级（#D36 硬上限） | 结构性差异，故意为之 |
| 条件触发 27% | 将领 Buff 多为常驻光环 | **可借鉴方向：白绿将也可做条件位**（如"本回合打出的第 N 个兵种 X"）增强构筑感 |

### 4.4 给将领池 v1 的三条具体建议

1. **商店供给按档分配**（白60/绿25/蓝10/紫4/红1 之类），掉落维持 1/2/4/8/16 权重——供给曲线与奖励幻想分离。
2. **白绿将引入条件触发位**（Balatro 最大类的启示）：约 1/3 白绿将改为条件 Buff（触发条件绑牌型/花色/兵种家族），比全常驻光环更有构筑味道。
3. **专属红将保留 1 张"复制位"**（Blueprint 位：复制相邻将领的被动）——线性体系内最强的构筑想象力来源，且天然是"值得围绕构建"的红将素质。

## 5. 数据局限
