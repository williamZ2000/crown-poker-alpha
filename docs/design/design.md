# 游戏设计文档

> 状态：讨论中（2026-07-03 更新）
> 基于旧版 Godot v1 大幅升级，目标形态：卡牌构筑 + 自走棋战斗
> 🚧 派系阵营 + 构筑维度待专项讨论

---

## 1. 核心体验

**成长构筑流** — 从手中几张散牌开始，通过战斗、经济、商店的持续累积，逐步养出一支有羁绊、有协同的强大军队。每局游戏都是一次"造战争机器"的过程。

**设计参考**: 金铲铲之战、杀戮尖塔、小丑牌

**情感曲线**:
- 开局：弱小，只有基础牌，英雄孤独
- 中期：滚雪球，经济起飞，羁绊凑齐，阵容成型
- 后期：碾压快感，神装满羁绊，阵法克敌

---

## 2. 玩法三层循环

### 2.1 微观层：回合

单次战斗回合流程：

```
抽牌 → 出牌召唤棋子 → 自动战斗 → 结算伤害
```

- **抽牌**: 从牌堆中抽取手牌（手牌上限待定）
- **出牌**: 打出扑克牌，牌转化为棋盘上的棋子
- **战斗**: 双方棋子自动攻击（自走棋模式），玩家不操作
- **结算**: 一方棋子全灭 or 回合上限到达，结算伤害

### 2.2 中层：关卡

```
多回合战斗 → 击败关卡 → 进商店 → 构筑升级 → 下一关
```

- 每关包含多个战斗回合（类似 Boss 战分段打）
- 商店系统是构筑核心——同样的金币如何分配，决定阵容方向
- 路线选择不在地图上，而在**商店购买决策**中

### 2.3 宏观层：整局

```
英雄成长路径 + 牌堆/棋子池持续进化 → 通关 or 失败
```

- 英雄从开局到终局持续成长（主动技能 + 被动 + 装备）
- 牌堆（棋子池）通过商店不断优化
- 整局有明确的起点和终点

## 3. 卡牌与棋子系统

### 3.1 点数 → 兵种线

点数决定棋子类型（而非花色），从前往后排列：

| 点数 | 兵种定位 | 特点 |
|------|----------|------|
| 2, 3, 4, 5 | 前排肉盾 | 高血量、低攻击、近战 |
| 6, 7, 8, 9 | 中坚过渡 | 攻防均衡 |
| 10, J, Q, K, A | 后排远程 | 低血量、高攻击、远程 |

### 3.2 牌型 → 特殊兵种

普通单牌/对子/三张按点数出对应普通棋子。特殊牌型召唤特殊单位：

| 牌型 | 召唤效果 |
|------|----------|
| 顺子（≥5连） | 骑兵/冲锋单位，突后排 |
| 同花（5张同花色） | 该花色对应的阵营精英兵种 |
| 炸弹（≥4同点） | 超模精英单位（攻城器械/巨龙等） |
| 同花顺 | 终极单位，兼具顺子机动+同花加成 |
| 三带二 | 混合编队：三张出前排 + 对子出后排 |
| 连对（≥3对） | 连锁召唤同名棋子，数量压制 |

### 3.3 基本规则

- 标准 52 张扑克牌（4 花色 × 13 点数）
- 牌堆可通过商店购买新牌扩充/升级
- 打出手牌 → 棋子立即上场（出牌即出兵）
- 手牌上限待定
- ⚠️ 花色**不直接对应职业定位**，避免随机性过强；花色作用体现在牌型判定（同花、同花顺）和派系叙事

## 4. 构筑系统总览

构筑分为**两条线**，平行推进、互相影响：

### 4.1 战斗单位构筑（"军队怎么打"）

决定棋盘上有什么兵、怎么配、多强。

| 来源 | 内容 | 说明 |
|------|------|------|
| **阵营兵种池** | 基础兵种 + 精英兵种 | 阵营决定可用兵种体系（§5） |
| **牌型召唤** | 普通牌→基础兵 / 特殊牌型→精英兵 | 出牌即出兵（§3.2） |
| **英雄特殊单位** | 将领、召唤物、魔兽等 | 英雄提供的超模/特殊单位（§6.2） |
| **商店道具** | 装备、Buff | 强化已有单位（§7） |

### 4.2 卡牌构筑（"手里有什么牌"）

决定牌堆质量、抽牌效率、能打出什么牌型。

| 来源 | 内容 | 说明 |
|------|------|------|
| **商店买牌** | 扩充/升级牌堆 | 改变概率分布（§7） |
| **商店删牌** | 精简牌堆 | 提高 key 牌上手率（§7） |
| **卡牌道具** | 手牌上限、额外抽牌等 | 改善抽牌效率（§7） |

### 4.3 构筑流派方向

玩家通过选牌策略 + 牌型目标 + 商店购买决定：

| 流派 | 核心思路 | 典型打法 |
|------|----------|----------|
| 物理射手队 | 后排远程火力 + 前排肉盾 | 堆大点数牌，前排4-5张，后排全力输出 |
| 法术爆发队 | AOE 清场 + 技能连携 | 凑同花/顺子出特殊兵种 |
| 坦克铁壁阵 | 超级前排拖时间，耗死对手 | 堆小点数牌出大量肉盾，后排少量输出 |
| 精英少而精 | 单兵质量碾压 | 囤炸弹/同花顺，场上单位少但属性爆炸 |
| 机制流 | 靠特殊牌型效果而非面板数值 | 连对连锁召唤、顺子骑兵冲锋 |

构筑方向由玩家决定的三个要素：
1. **选牌策略**（偏向小点数堆数量 or 大点数堆质量）
2. **牌型目标**（追求顺子/炸弹/同花的不同路线）
3. **商店购买**（买牌扩池 or 买道具强化 or 刷新找 key 牌）

## 5. 派系阵营 🚧

### 5.1 设计原则

- 游戏开始前选择派系阵营，全程不变
- 不同派系决定不同的**兵种体系**（包含基础兵种和精英兵种）
- 派系与张总自有 IP/故事背景绑定，具体派系名称和设定后续确定

### 5.2 阵营兵种体系

每个阵营拥有一套完整的兵种树：

| 层级 | 内容 | 召唤来源 |
|------|------|----------|
| 基础兵种 | 阵营特色的普通战士（剑士、弓手、骑兵等） | 单牌/对子/三张 |
| 精英兵种 | 阵营特色的强力单位（圣骑士、大法师、攻城车等） | 特殊牌型（顺子/同花/炸弹） |
| 传奇单位 | 阵营终极单位（龙骑士、天使等） | 同花顺 |

### 5.3 阵营天赋（"海克斯"式引导）

派系 + 英雄的组合产生**阵营天赋效果**——为阵容构筑提供方向性引导，但**不锁死**玩家选择。

**工作机制**：
- 开局选择派系 + 英雄 → 获得阵营天赋被动
- 天赋给出明确增益方向（如："所有前排棋子 +15% 血量"）
- 玩家**可以遵循**引导走坦克路线，也**可以忽略**走其他路线
- 天赋只是"顺风加成"，不是强制要求

**示例**（非最终）：

| 派系 | 英雄 | 阵营天赋 | 引导方向 |
|------|------|----------|----------|
| 帝国 | 将军 | 前排棋子 +15% 血量 | 坦克铁壁阵 |
| 帝国 | 射手统领 | 后排棋子 +10% 攻击力 | 物理射手队 |
| 精灵 | 风行者 | 所有棋子 +1 射程 | 风筝拉扯流 |
| 亡灵 | 死灵法师 | 棋子阵亡后 50% 概率复活一次 | 数量压制流 |

**设计意图**：
- 增加重玩性：同一派系配不同英雄，玩法完全不一样
- 降低选择门槛：新手从天赋中获得明确方向指引
- 保留自由度：老手可以无视天赋，玩自己的构筑

### 5.4 派系数据结构（预留）

每个派系定义为：

| 字段 | 说明 |
|------|------|
| 名称 | 派系名 |
| 兵种池 | 该派系的基础兵种 + 精英兵种列表 |
| 被动加成 | 全局效果（如：所有前排 +15% 血量） |
| 特殊牌型效果 | 打出特定牌型时的额外增益 |
| 专属英雄 | 该派系可选的英雄（1-N 个） |

### 5.5 派系编辑器（开发工具）

**需求**：不硬编码派系逻辑，提供可视化编辑器，方便添加/调整派系。

**技术方案**（初步）：
- Unity ScriptableObject 存储派系配置数据
- Inspector 面板可视化编辑属性
- 新增派系只需创建新的 ScriptableObject 资产，无需改代码
- 开发早期先做 1-2 个派系跑通流程，编辑器工具后续迭代

## 6. 英雄系统

### 6.1 选择

- 开局选择一个英雄，全程携带
- 英雄必须属于所选派系

### 6.2 英雄能力

| 类型 | 说明 |
|------|------|
| 被动加成 | 全局增益（如：所有红桃棋子 +X% 攻击力） |
| 主动技能 | 战斗中可手动/自动触发（如：AOE 伤害、治疗） |
| 特殊兵种奖励 | 英雄专属的强力单位（将领、召唤物、魔兽等），数值超模或机制独特 |
| 阵营天赋 | 派系+英雄组合产生的方向性引导（§5.3） |

### 6.3 成长路径

- 英雄随关卡推进获得经验/升级
- 升级解锁新技能 or 强化已有技能
- 可装备道具（商店购买）进一步定制

## 7. 棋盘

### 7.1 布局

- 双方各一个 **4 × N** 半场（N 待定，预设 8-12）
- 前排/后排可区分，对应肉盾/输出站位

### 7.2 阵型系统

- 提供**预设阵型模板**（前排放肉盾、后排放输出等），一键切换
- 支持手动拖拽摆放
- 目标：不拖慢游戏节奏，准备阶段控制在 30 秒内

### 7.3 战斗规则

- 自走棋式自动战斗，玩家不可干预
- 棋子按攻速自动攻击射程内最近的敌方棋子
- 英雄站在棋盘特定位置（后方），可释放主动技能
- 一方棋子全灭 or 回合上限到达时，回合结束

## 8. 商店系统（构筑核心）

### 8.1 出现时机

每关战斗结束后进入商店。

### 8.2 商品类型

| 类型 | 说明 | 影响线 |
|------|------|--------|
| 新牌 | 加入牌堆，扩充棋子池 | 卡牌线 |
| 升级牌面 | 替换牌堆中的牌为更高品质 | 卡牌线 |
| 道具/装备 | 给英雄或棋子加 Buff | 单位线 |
| 特殊单位 | 雇佣强力棋子（雇佣兵、魔兽等） | 单位线 |
| 刷新 | 花钱刷新商品列表 | — |

### 8.3 构筑哲学

- 同样的金币，不同花法导致不同阵容
- 买牌 → 扩充棋子池 → 更容易凑牌型 → 更多特殊单位
- 买道具 → 强化现有阵容 → 即时战力提升
- 买特殊单位 → 直接获得超模棋子 → 短期爆发
- 刷新 → 找关键牌/道具 → 高风险高回报
- **商店就是路线选择**

## 10. PvE 关卡设计

### 10.1 关卡结构

- 线性闯关，难度递增
- 普通关 + Boss 关交替
- Boss 关有特殊机制（待设计）

### 10.2 敌人设计

- 敌人也有棋子阵容和英雄
- 不同关卡敌人阵容主题不同（如：全是黑桃的刺客阵）
- 敌人的棋子也可能有特殊效果
