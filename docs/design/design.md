## 1. 核心体验

**成长构筑流** — 从手中几张散牌开始，通过战斗、经济、商店的持续累积，逐步养出一支有羁绊、有协同的强大军队。每局游戏都是一次"造战争机器"的过程。

**设计参考**: 金铲铲之战、杀戮尖塔、小丑牌

**情感曲线**:
- 开局：弱小，只有基础牌，英雄孤独
- 中期：滚雪球，经济起飞，Buff 链启动，军队逐步成型
- 后期：碾压快感，将领+装备全力加持，神装军队横扫战场

## 2. 回合系统（核心操作闭环）

### 2.1 回合四阶段

每个战斗回合按以下顺序执行：

```
抽牌(自动) → 出牌(多轮,玩家操作) → 战斗(自动) → 结算(展示结果)
```

#### 2.1.1 抽牌阶段（自动）

| 参数 | 值 | 说明 |
|------|-----|------|
| 起手 | 第 1 回合抽 **13 张** | 开局手牌充足，策略空间大 |
| 手牌上限 | **13 张** | 可通过道具/商店增加 |
| 每回合补牌 | 自动从牌堆补满至上限 | 保持每回合起手一致 |
| 弃牌换牌 | 可弃 N 张换抽等量（N 基础值待定，可成长） | 类似小丑牌 discard 策略 |
| 弃牌时机 | **出牌阶段内随时** | 玩家可在出牌阶段任意时刻弃牌换抽 |

- 牌堆为初始标准 52 张（4 花色 × 13 点数），可通过商店扩充/升级
- 弃牌换牌为可选操作，玩家可跳过直接进入出牌阶段

#### 2.1.2 出牌阶段（多轮，玩家操作）

**核心机制：多轮出牌，随时开战。** 棋子跨回合留存（§3.4），出牌 = **增援补充**军队。

| 参数 | 值 |
|------|-----|
| 轮次上限 | 基础 **3 轮**（道具可增加） |
| 单轮出牌数 | **无上限** |
| 衔接方式 | 玩家随时点击"开战"进入战斗，不强制用完轮次 |
| 站位调整 | 每轮出牌后棋子落位，可**手动拖拽自由调整**（RTS 式，§7.1） |
| 满员处理 | 棋盘达部署上限 → 多余棋子进入**支援区**（§3.4.4） |

**牌型判定**：系统根据选中手牌自动识别牌型，支持灵活组合：

| 牌型类别 | 触发条件 | 召唤效果 |
|----------|----------|----------|
| 单牌 / 对子 / 三条 | 任意 | 每张出对应基础兵种（按档位） |
| 连对 | ≥3 对连续对子（如 334455） | 对子家族加长：每张 1 个（兵种按派系，见派系兵种设计.md） |
| 连三张 | ≥2 连连续三条（如 333444） | 三张家族加长：每张 1 个（兵种按派系） |
| 三带二 | 三条+对子 | 3 个三张家族兵 + 2 个对子家族兵 + 小增益 Buff |
| 顺子 | ≥5 张连续 | 指数召唤顺子家族兵（基准 5 张 = 1 个，兵种按派系） |
| 炸弹 | ≥4 张同点（可超 4 张） | 指数召唤炸弹家族兵（基准 4 炸 = 1 个） |
| 同花顺 | ≥5 张连续同花色（可超 5 张） | 指数召唤同花顺家族兵（基准 5 张 = 1 个） |
| 双同花顺 🎉 彩蛋 | 同花色 ≥5 连对（如 ♠33♠44♠55♠66♠77） | 按连对召唤（每张 1 个）+ 额外触发 L9/L10 将领掉落（5连=L9，6连+=L10） |

**出牌轮次的经济博弈**：

玩家拥有基础 3 轮出牌机会。超出阵容需求的出牌轮次是一种**资源**——可以转化为金币，但需要承担风险。

| 玩家选择 | 操作 | 效果 |
|----------|------|------|
| 稳健部署 | 用满 3 轮或接近 3 轮，打出尽可能多的手牌 | 阵容最大化强化，无额外金币 |
| 贪婪存钱 | 提前结束出牌（少用轮次），未使用的轮次转换为金币 | 获得金币，但**当回合敌方棋子属性增强或数量增加** |

> 💡 设计意图：利用指数增长难度和可扩部署上限，创造持续的"要不要多部署一轮"的张力。玩家永远需要更强——但省下来的轮次可以变金币、吃利息。

**关键前提**：
- 部署上限固定 36（§3.4.2），超出部分进入支援区（§3.4.4）
- 关卡难度指数增长（§10.1），始终存在增援压力
- 因此"军队已足够强、不需要再部署"是罕见的——玩家面临的是**真实的选择**，而非系统误判

#### 2.1.3 战斗阶段（自动）

参见 §7 棋盘与战斗规则。关键约束：

| 约束 | 值 |
|------|-----|
| 伤害公式 | 物攻×100/(100+护甲)；魔攻×100/(100+魔抗)（§7.3） |
| 绝对时限 | **180 秒**（防止卡死） |
| 静默结束 | 双方不再产生伤害后 **10 秒**自动结束 |
| 玩家操作 | 不可干预（自走棋模式） |

#### 2.1.4 结算阶段

- 胜负判定 → 金币结算 → 高效/低效奖惩 → 进入下一回合 or 商店
- 一方棋子全灭 or 战斗时限触发 → 回合结束

### 2.2 中层：关卡

```
3 回合战斗（每回合战斗后商店）→ 击败关卡 → 进入下一关
```

| 参数 | 值 |
|------|-----|
| 每关结构 | **统一 3 回合**，最后一回合打 Boss |
| 难度曲线 | **指数增长** |
| 难度节点 | 关 4、关 8 **陡增** |
| 商店频率 | **每回合结束后**（§8.1） |
| 利息结算 | **每回合结束后**（§9.1） |

### 2.3 宏观层：整局

```
派系+英雄选择 → 闯关(无上限) → 持续构筑 → 失败 or 无尽攀升
```

- 总关数**无上限**，难度指数增长
- 目标从"通关"变为"能走多远"
- 英雄持续成长，牌堆/棋子池持续进化
- ⚠️ PvE 闯关：**败一次即终局**

### 2.4 局外成长（Meta-Progression）🆕

败即终局，但每次对局都有累积价值。

#### 2.4.1 解锁体系

| 解锁类型 | 获取方式 | 说明 |
|----------|----------|------|
| 新阵营 | 达到指定关卡 / 累计通关次数 | 扩充可选的派系 |
| 新英雄 | 使用特定阵营通关 / 达成条件 | 同一阵营下的新英雄选项 |
| 新将领 | 阵营专属解锁 | 阵营兵种池中的新将领单位 |
| 更高难度 | 通关当前最高难度 | 解锁下一级难度 |

#### 2.4.2 难度层级 🚧

参照小丑牌，更高难度不仅提升敌人数值，还附带**额外玩法限制**：

| 难度层级 | 解锁条件 | 内容变化 |
|----------|----------|----------|
| 普通 | 默认可用 | 基础数值曲线 |
| 困难 | 通关普通 | 敌人属性 +X%，增加 1 个全局限制条件 |
| 专家 | 通关困难 | 敌人属性 +X%，增加 2-3 个限制条件 |
| 更高… | 逐级解锁 | 🚧 具体层级数量待定 |

> 💡 玩法限制条件示例（BS 阶段，非最终）：手牌上限 -1、弃牌次数 -1、商店价格 +20%、敌方每关额外多 1 个单位、将领槽 -1 等。目标是让高难度不仅是"敌人更肉"。

#### 2.4.3 开放的 BS 问题 🚧

| 问题 | 状态 |
|------|------|
| 难度层级的具体数量 | 待定 |
| 每层难度的具体限制条件 | 待设计 |
| 解锁条件的精确数值（打到第几关） | 待平衡性 |
| 各阵营/英雄/将领的具体解锁条件分布 | 待内容设计 |

## 3. 卡牌与棋子系统

### 3.1 点数 → 兵种档位

点数决定棋子所属**档位**（而非花色），从前往后排列：

| 档位 | 点数 | 定位 |
|------|------|------|
| 数字档 | 2-10 | 常规兵种，数值随点数递增（2 最弱、10 最强）；内部可细分前/中/后排定位 |
| 人头档 | J / Q / K | 独立兵种，强于同长度数字档 |
| A 档 | A | 加强版数字兵种（数值最高，定位近似数字档上位） |

> 混合牌型按**最高点数**判定档位（#D18）：最大点数是 A → A 档；J/Q/K → 人头档；2-10 → 数字档。**顺子例外**：家族兵三合一（如帝国铁骑），不按档位区分（§派系兵种设计）。

### 3.2 牌型 → 兵种映射（定稿 #D18）

牌型由系统根据玩家选中的手牌**自动判定**。核心规则：**家族决定兵种类别与数量规则，牌面类别（数字/人头/A）决定兵种分档**；兵种具体名称与定位**按派系定义**（见 [派系兵种设计.md](./派系兵种设计.md)）。

| 家族 | 兵种分档 | 数量规则 |
|------|----------|----------|
| 单牌 | 数字 / 人头 / A | 每张 1 个 |
| 对子 / 连对 | 数字 / 人头 / A | 每张 1 个（对子=2、连对=张数） |
| 三张 / 连三张 | 数字 / 人头 / A | 每张 1 个（三张=3、连三张=张数） |
| 顺子 | 数字 / 人头 / A | 指数：基准 5 张 = 1 个，每 +2 阶翻倍 |
| 同花顺 | 数字 / 人头 / A | 指数：基准 5 张 = 1 个，每 +2 阶翻倍 |
| 炸弹 | 数字 / 人头 / A | 指数：基准 4 炸 = 1 个，每 +2 阶翻倍 |

**数量公式**：`数量 = round(2^((长度 − 基准)/2))`，仅作用于特殊线（顺子/同花顺/炸弹）；基础线（单牌/对子/连对/三张/连三张）每张 1 个。

**档位判定**：混合牌型以最大点数为准——最大点数是 A → A 档；J/Q/K → 人头档；2-10 → 数字档。A 低牌顺（A2345）最大为 5，按数字档。**顺子例外**：家族兵三合一（如帝国铁骑），不按档位区分（§派系兵种设计）。

**三带二**：打出"三条+对子" = 3 个三张家族兵（按三条档位）+ 2 个对子家族兵（按对子档位）+ 一点增益 Buff（效果待内容设计）。飞机、同花已从牌型表移除（#D17/#D18）。

**双同花顺 🎉（彩蛋超牌型）**：同花色 ≥5 连对 = 两张相同同花顺叠放（两副牌特性，每花色点数有 2 张）。本质仍是**连对**——按连对规则召唤（每张 1 个），额外触发 **L9/L10 将领掉落**（5连 = L9，6连及以上 = L10，§3.2.1）。

> 💡 灵活判定：炸弹可从 4 张起，同花顺可从 5 张起，只要手牌能连上即可多轮出牌。

#### 3.2.1 高难度牌型的额外收益（定稿 #D20）

**三类收益机制**：

1. **战斗/战术特效 → 绑定棋子**：炸弹/同花顺等召唤的兵种自带特效（眩晕/削弱/护盾/斩杀/锁定等），特效长在兵身上，不是独立奖励
2. **经济 + 构筑资源 → 长效率牌**：13 连顺子、长连对、长连三张打出时获得金币 / 附魔机会 / 宝石 / 牌堆操作等构筑资源，服务卡牌线
3. **将领掉落 → 炸弹/同花顺**：概率掷出六档结果（不掉落 / 白 / 绿 / 蓝 / 紫 / 红），驱动源 = 牌型稀有度等级，与商店/成长解耦

**将领掉落等级映射**：

| 掉落等级 | 触发牌型 |
|----------|----------|
| 1 | 4炸 |
| 2 | 5炸 / 同花顺5张 |
| 3 | 6炸 / 同花顺7张 |
| 4 | 7炸 / 同花顺9张 |
| 5 | 8炸 / 同花顺11张 |
| 6 | 9炸 / 同花顺13张 |
| 7 | 10炸 |
| 8 | 11炸 |
| 9 | 12炸 / 双同花顺5连（彩蛋） |
| 10 | 13炸及以上（13/14炸+）/ 双同花顺6连及以上 |

**掉落分布表**（定稿 #D23，数值可随平衡迭代微调）：

| 掉落等级 | 不掉落 | 白 | 绿 | 蓝 | 紫 | 红 |
|----------|--------|-----|-----|-----|-----|-----|
| 1 | 70% | 28% | 2% | — | — | — |
| 2 | 50% | 35% | 12% | 3% | — | — |
| 3 | 30% | 30% | 25% | 12% | 3% | — |
| 4 | 15% | 25% | 30% | 20% | 8% | 2% |
| 5 | 5% | 15% | 28% | 28% | 18% | 6% |
| 6 | 0% | 8% | 22% | 30% | 26% | 14% |
| 7 | 0% | 3% | 15% | 28% | 32% | 22% |
| 8 | 0% | 0% | 9% | 26% | 37% | 28% |
| 9 | 0% | 0% | 4% | 24% | 40% | 33% |
| 10 | 0% | 0% | 0% | 18% | 42% | 40% |

> 机制：金铲铲式概率分布——等级越高分布右移，但低档不消失；不掉落仅在高等级归零。掉落的将领品质 = 白绿蓝紫红（#D15）。L8/L9/L10 为紫红主导（65%/73%/82%）。品质权重：白1 / 绿2 / 蓝4 / 紫8 / 红16（#D23）。

> 🎉 双同花顺是彩蛋级超牌型：概率 ~0.001%（26 张），实战几乎不可见，触发了就是天选之人——本质按连对出牌，额外拿一次 L9/L10 顶级掉落（5连=L9，6连+=L10）。

### 3.3 基本规则

- 标准 52 张扑克牌（4 花色 × 13 点数）
- 牌堆可通过商店购买新牌扩充/升级
- 打出手牌 → 棋子立即上场（出牌即出兵）
- **手牌上限 13 张**（道具可增加），起手抽 13 张
- 每回合自动补满至手牌上限
- 可弃牌换抽（张数上限可成长）
- **多轮出牌**，基础 3 轮（道具可增加），随时可点"开战"结束
- **站位可调**：每轮出牌后棋子落位，玩家可手动调整
- ⚠️ 花色**不直接对应职业定位**，避免随机性过强；花色作用体现在牌型判定（同花顺）和派系叙事

### 3.3.1 花色与派系收益

**核心定位**：花色不直接决定棋子职业，但**部分派系对特定花色有额外收益**——为出牌决策增加一层"派系偏好"维度。

| 机制 | 说明 |
|------|------|
| 触发条件 | 打出该派系偏好的花色牌 |
| 收益形式 | 额外金币 / 该棋子属性加成 / Buff 层数叠加等（具体因派系而异） |
| 不强制 | 不是"必须打红桃"，而是"顺带收益"，玩家可完全忽略 |
| 与牌型的关系 | 花色收益独立于牌型判定，两者并行计算 |

> 💡 例如：某派系偏好黑桃。打出黑桃牌正常召唤棋子，同时额外 +2 金币。影响出牌顺序决策 —— 优先打黑桃牌还是优先凑牌型？

**设计意图**：
- 让花色在博弈中有游戏性意义（不只是叙事），但不主导战局
- 不同派系偏好不同花色 = 增加重玩性和运营深度
- 与阵营天赋（§5.3）形成双层引导：天赋给阵容方向，花色偏好给出牌优化方向

### 3.4 棋子留存与升级 🆕

**核心理念**：棋子跨回合留存，打造"组建自己的军队"的养成感。

#### 3.4.1 棋子生命周期

| 状态 | 触发条件 | 结果 |
|------|----------|------|
| 存活 | 战斗结束时 HP > 0 | 跨回合保留，进入下回合 |
| 阵亡 | 战斗中 HP 归零 | **默认永久消失** |
| 🍀 受伤存活 | 阵亡时 **5% 基础概率**触发（可被 Buff 提升） | 保留至下回合，**50% HP**（可选叠加虚弱 debuff，后续讨论） |

#### 3.4.2 棋盘部署（定稿）✅

| 参数 | 值 |
|------|-----|
| 部署方式 | **RTS 自由部署**，无固定格子，单位在己方半场任意摆放 |
| 部署上限 | **固定 36**（含英雄 + 将领 + 棋子；第一版不做成长，待实际效果再定） |
| 半场区域 | 双方各占一半（左右半场对称），纵向开放 |
| 边界 | 单位不可出界、不可被推出半场 |
| 出牌含义 | 出牌 = **增援**，新棋子加入军队；满员后新棋子进入支援区（§3.4.4） |

#### 3.4.3 多轮出牌的新意义

有了棋子留存后，多轮出牌从"凑组合"升级为"分层部署军队"：

```
第 1 轮 → 部署前排肉盾
第 2 轮 → 补充后排火力
第 3 轮 → 上线将领/特殊单位
```

#### 3.4.4 支援区（预备队）

| 参数 | 值 |
|------|-----|
| 触发 | 棋盘单位达部署上限，又打出新棋子 |
| 去向 | 进入**支援区**（待部署队列） |
| 容量 | **36**（与部署上限一致） |
| 补位 | 战场上有人阵亡后，支援区棋子**波次增援**自动上场（自动按类型优先补位：先前排、再后排；玩家预设增援顺序留作扩展） |
| 入场位置 | 从己方后排边缘入场 |

#### 3.4.5 棋子升级

### 3.5 特殊属性牌 🆕

**核心定位**：普通牌只有花色+点数；特殊属性牌 = 花色 + 点数 + **一个附加属性**。参照《小丑牌》塔罗牌体系，特殊属性不影响牌型判定——牌型只看花色+点数，附加属性独立运算。

#### 3.5.1 属性分类

| 类别 | 小丑牌原型 | 效果 | 例子 |
|------|-----------|------|------|
| 数值增益 | 加分牌 | 打出时 → 场上全体棋子临时 Buff | "激励牌"：打出时全体物攻+3（本回合） |
| 倍率效应 | 加倍乘数 | 打出时 → 某个已有效果翻倍 | "暴击牌"：打出时下一张牌的棋子属性 ×2 |
| 万能牌 | 百搭花色 | 此牌可视为任意花色参与牌型判定 | "百搭牌"：红桃 7 可当黑桃 7 用 |
| 留手增益 | 黄金牌/钢铁牌 | 留在手中每回合自动触发效果 | "金币牌"：在手中每回合 +3 金币；"钢铁牌"：在手中全体护甲+1 |
| 改变牌面 | 石头牌/玻璃牌 | 打出后触发特殊效果 | "石头牌"：棋子额外护甲 +X；"玻璃牌"：打出后该牌从牌堆中**永久消失**，带来强力效果（具体数值待定） |
| 经济牌 | 直接给钱 | 打出时直接获得金币 | "黄金牌"：打出时 +15 金币 |

> 💡 "留手增益"类牌制造核心张力：留 = 每回合吃效果 vs 打 = 变成棋子

#### 3.5.2 获取方式

| 来源 | 说明 |
|------|------|
| 商店直接出售 | 已经附了属性的特殊牌，价格高于普通牌 |
| 商店"附魔服务" | 花钱给手中某张牌附加一个随机/指定属性 |
| 将领被动 | 某些将领提供"每关开始随机附魔 1 张牌" |

#### 3.5.3 特殊属性牌 vs 直接 Buff 对比

| | 直接 Buff（商店即时生效） | 特殊属性牌 |
|------|--------------------------|-----------|
| 生效方式 | 买了立刻全局生效 | 需要抽到、打出 or 留在手中 |
| 持续性 | 永久 | 一次性（打出）或本局（留手） |
| 随机性 | 确定性购买 | 需要摸到这张牌 |
| 策略深度 | 低（买了就有） | 高（留 vs 打的决策） |

#### 3.5.4 开放的 BS 问题 🚧

| 问题 | 状态 |
|------|------|
| 同一张牌能否叠加多个特殊属性？ | 待讨论 |
| 特殊属性牌的稀有度分布 | 待设计 |

## 4. 构筑系统总览

构筑分为**两条线**，通过共用**金币**资源产生互动。玩家自行决定每笔金币投向哪条线——像金铲铲"买棋 vs 攒经济"一样，运营思路决定胜负。

> 💡 双线互动是游戏的核心创新点，详见 §4.5。

### 4.1 战斗单位构筑（"军队怎么打"）

决定棋盘上有什么兵、怎么配、多强。

| 来源 | 内容 | 说明 |
|------|------|------|
| **阵营兵种池** | 基础兵种 + 精英兵种 | 阵营决定可用兵种体系（§5） |
| **牌型召唤** | 普通牌→基础兵 / 特殊牌型→精英兵 | 出牌即出兵（§3.2） |
| **英雄特殊单位** | 将领、召唤物、魔兽等 | 英雄提供的超模/特殊单位（§6.2） |
| **商店** | 将领（占槽+全局Buff）、装备（占槽+被动）、直接强化Buff（无槽） | 金币购买（§8） |

### 4.2 卡牌构筑（"手里有什么牌"）

决定牌堆质量、抽牌效率、能打出什么牌型。

| 来源 | 内容 | 说明 |
|------|------|------|
| **商店买牌** | 扩充/升级牌堆 | 改变概率分布（§8） |
| **商店删牌** | 精简牌堆 | 提高 key 牌上手率（§8） |
| **卡牌道具** | 手牌上限、额外抽牌等 | 改善抽牌效率（§8） |
| **将领加成** | 某些将领提供抽牌+/弃牌+/牌堆概率改变 | 单位线反哺卡牌线（§4.5） |

### 4.3 构筑流派方向

玩家通过选牌策略 + 牌型目标 + 商店购买决定：

| 流派 | 核心思路 | 典型打法 |
|------|----------|----------|
| 物理射手队 | 后排远程火力 + 前排肉盾 | 堆大点数牌，前排4-5张，后排全力输出 |
| 法术爆发队 | AOE 清场 + 技能连携 | 凑顺子/炸弹出特殊兵种 |
| 坦克铁壁阵 | 超级前排拖时间，耗死对手 | 堆小点数牌出大量肉盾，后排少量输出 |
| 精英少而精 | 单兵质量碾压 | 囤炸弹/同花顺，场上单位少但属性爆炸 |
| 机制流 | 靠特殊牌型效果而非面板数值 | 连对连锁召唤、顺子骑兵冲锋 |

构筑方向由玩家决定的三个要素：
1. **选牌策略**（偏向小点数堆数量 or 大点数堆质量）
2. **牌型目标**（追求顺子/炸弹/同花顺的不同路线）
3. **商店购买**（买牌扩池 or 买道具强化 or 刷新找 key 牌）

### 4.4 Buff 被动叠加系统 🆕

**设计定位**：取代传统自走棋"同阵营羁绊"，改为**小丑牌式 Buff 自由叠加**。玩家通过**将领兵种**和**装备**两种载体收集被动 Buff，有槽位限制、需要取舍。

#### 4.4.1 载体类型

| 载体 | 说明 | 获取方式 | 占用槽位 |
|------|------|----------|----------|
| 英雄自身被动 | 开局选定英雄时附带，全程携带 | 选英雄 | 不占槽（1 个固定） |
| 将领兵种 | 上场后提供全局被动 Buff，同时参与战斗 | 商店 / 关卡奖励 | 将领槽 ×6 |
| 装备 | 英雄身上的道具，提供被动 Buff | 商店 / 关卡奖励 | 装备槽 ×2 |

> 💡 将领槽和装备槽独立计算，不互相占用。槽位数可成长（道具/关卡奖励扩展）。

#### 4.4.2 将领兵种 vs 普通兵种

| | 普通兵种 | 将领兵种 |
|------|----------|----------|
| 棋盘行为 | 战斗 | 战斗 + 全局 Buff |
| 被动 Buff | ❌ | ✅ 全局被动生效 |
| 上场限制 | 无（只要从手牌打出） | 🚧 有槽位限制 |
| 获取方式 | 出牌召唤 | 商店购买 / 关卡奖励 |
| 稀有度 | 普通 | 白色 / 绿色 / 蓝色 / 紫色 / 红色（按稀有程度命名，获取难度递增） |

> 将领既是强力棋子也是 Buff 来源，属于"质变"型单位。每个阵营有自己的将领池。

**将领稀有度（五档，按稀有程度命名）**：

| 档位 | 获取难度 | 强度定位 |
|------|----------|----------|
| 白色 | 最常见 | 略强于普通棋子，Buff 为主 |
| 绿色 | 较常见 | 战力渐强 |
| 蓝色 | 较少见 | 明显强于普通棋子 |
| 紫色 | 稀有 | 战场核心级 |
| 红色 | 极稀有 | 明显超模，值得围绕构建 |

**将领定位（五类，传统命名）**：

| 定位 | 战斗角色 | 特长 |
|------|----------|------|
| 坦克 | 前排肉盾 | 扛线，Buff 偏防御/护甲 |
| 战士 | 近战输出 | 冲锋，Buff 偏攻击/攻速 |
| 火力 | 远程输出（含法师） | 输出，Buff 偏命中/射程/法术 |
| 支援 | 参与战斗 | 提供直接 Buff（全局增益核心价值） |
| 统御 | 参与战斗 | 提供构筑帮助（抽牌/牌堆/经济/回收等卡牌线增益） |

**原则**：
- 所有将领都"参战 + 携带被动 Buff"，五类定位是特长倾向，非排他
- **定位与稀有度解耦**：白色也有统御型，红色也有坦克型；红色 = 强度上限更高
- **全红可行但不必然最优**：稀有度决定强度上限，定位决定互补价值，6 槽取舍由两者共同构成
- 🚧 部分将领可拥有**多定位**（如坦克+统御），具体内容设计时再细化

#### 4.4.3 Buff 作用环节

Buff 可以作用于回合的四个阶段，丰富策略多样性：

| 环节 | 示例效果 | 设计密度 |
|------|----------|----------|
| 🃏 抽牌阶段 | 额外抽牌 +N、弃牌次数 +1、手牌上限 +N、某花色概率提升 | 中等 |
| 🎯 出牌阶段 | 某花色点数视为 +X、出牌轮次 +1、某牌型判定条件放宽 | 高（核心玩法） |
| ⚔️ 战斗阶段 | 全体全攻+X%、前排获得护盾、远程攻速 +X%、击杀触发回血 | 高（主力战场） |
| 💰 结算阶段 | 金币 +X%、额外经验、概率获得额外奖励 | 低（少而精） |

> 💡 结算阶段 Buff 保持克制——此处 Buff 只应"锦上添花"，不应成为经济主导因素。

| 事项 | 状态 | 关联 |
|------|------|------|
| 将领具体内容设计（技能/数值/多定位组合） | 待内容设计 | M0-03d |
| 装备是否有主动效果 | 待讨论 | M0-03f 英雄技能联动 |
| 具体 Buff 池设计 | 后续内容设计 | — |

#### 4.4.5 Buff 叠加规则（已定稿）

**核心原则**：任何叠加都是**线性加法**，只做加法不做乘法。

```
最终值 = 基础值 + Σ固定加成 + 基础值 × Σ百分比加成
```

| 场景 | 计算方式 | 示例 |
|------|----------|------|
| 固定加成叠加 | 直接相加 | 两个 DEF+2 → DEF+4 |
| 百分比加成叠加 | 百分比相加后乘以基础值 | 两个 +20% ATK → ×1.4（非 ×1.44） |
| 固定 + 百分比混合 | 互不放大，各算各的 | 基础 100，+20% ATK 与 +2 ATK → 122 |

- 百分比只基于**基础值**计算，固定值只做加法，两者互不放大
- 概率类 Buff（如受伤存活率）可叠加至 100%，堆满即构筑成型奖励；不设上限、不设"负面优先"规则
- 数值膨胀兜底暂不设计（将领 6 槽 + 装备 2 槽天然限制 Buff 来源数量）
- 备注：示例中 ATK/DEF 为通用表达，实际细分为物攻/魔攻、护甲/魔抗（§7.3）

### 4.5 双线互动机制 🆕

**核心原则**：金币是唯一共用资源，玩家自主决定投入方向。**游戏不按关卡节奏交替主导两线**——运营思路决定胜负。

#### 4.5.1 互动矩阵

```
                金币（唯一共用资源）
               ┌───┬───┬───┐
               ↓   ↓   ↓   ↓
            买将领 改牌堆 买装备 直接Buff
               │   │   │   │   （无槽消耗）
         ┌─────┴───┴───┴───┴─────┐
         │     单位线 ←→ 卡牌线    │
         │  将领可影响抽牌/牌堆   │
         │  商店投入方向完全自由   │
         └────────────────────────┘
```

#### 4.5.2 已确立的互动

| 互动方向 | 内容 | 实现方式 |
|----------|------|----------|
| **单位线 → 卡牌线** | 某些将领提供抽牌+/弃牌+/手牌上限+/牌堆概率改变 | 将领的被动 Buff 类别中包含"卡牌类增益" |
| **金币分配分歧** | 同笔金币要在将领/牌堆/装备/直接Buff之间选 | 商店四类商品共用统一价格体系（§8） |
| **特殊单位回收** | 部分特殊将领或功能牌可操作场上多余单位（回手/回收/转化） | 非通用机制，仅特定载体持有 |

#### 4.5.3 裁剪掉的方案

| 方向 | 原因 |
|------|------|
| 战斗中卡牌实时增益 | 张总不喜欢 |
| 通用回收机制 | 削弱手牌管理意义 |
| 分阶段交替主导 | 应该玩家自主决定，不由游戏规划 |

#### 4.5.4 开放的 BS 问题

| 问题 | 状态 |
|------|------|
| 将领具体内容设计（技能/数值/多定位组合） | 待内容设计 |
| 两种极端策略（全投单位 vs 全投卡牌）是否都能通关？ | 待平衡性验证 |
| 金币产出的节奏应该如何设计来支撑多选一的商店模型？ | 待商店/经济讨论 |

## 5. 派系阵营 ✅（v1 帝国）

### 5.1 设计原则

- 派系与《天瀑》世界观绑定（叶历 55 年，天灵帝国与天神卷土重来）
- **v1 单派系开局**：叶氏帝国（贪多嚼不烂，先跑通一个派系），多派系作为后续扩展
- 不同派系决定不同的**兵种体系**（包含基础兵种和精英兵种）
- **英雄池与将领池分离**：英雄（§6）= 独特单位，不可阵亡、固定后排；将领（§4.4）= 槽位 Buff 载体 + 参战，两者各自独立成池
- 角色进度以张总为准：小说已写的直接用，未写到的可游戏先行

### 5.2 阵营兵种体系

每个阵营拥有一套完整的兵种树：

| 层级 | 内容 | 召唤来源 |
|------|------|----------|
| 基础兵种 | 阵营特色的普通战士（对应数字/人头/A 三档） | 基础线：单牌/对子/连对/三张/连三张（每张 1 个） |
| 精英兵种 | 阵营特色的强力单位 | 特殊线：顺子/炸弹（指数召唤） |
| 传奇单位 | 阵营终极单位 | 同花顺（指数召唤） |

> 🚧 具体兵种名称与数值待内容设计（牌型→兵种映射已定稿 #D18；兵种按派系填充，见 [派系兵种设计.md](./派系兵种设计.md)）。

### 5.3 阵营天赋（"海克斯"式引导）

派系 + 英雄的组合产生**阵营天赋效果**——为阵容构筑提供方向性引导，但**不锁死**玩家选择。

> v1 组合：**帝国 × 叶斌云**（帝国太子），具体天赋效果待内容设计。

**工作机制**：
- 开局选择派系 + 英雄 → 获得阵营天赋被动
- 天赋给出明确增益方向（如："所有前排棋子 +15% 血量"）
- 玩家**可以遵循**引导走坦克路线，也**可以忽略**走其他路线
- 天赋只是"顺风加成"，不是强制要求

**示例**（非最终）：

| 派系 | 英雄 | 阵营天赋 | 引导方向 |
|------|------|----------|----------|
| 帝国 | 叶斌云 | 🚧 待内容设计 | — |

**设计意图**：
- 增加重玩性：同一派系配不同英雄，玩法完全不一样
- 降低选择门槛：新手从天赋中获得明确方向指引
- 保留自由度：老手可以无视天赋，玩自己的构筑

### 5.4 宝石与魔法体系

**核心机制**：赛尔玛尼亚宝石是天瀑世界中唯一的魔法来源——**只有佩戴宝石的角色才能使用魔法（法术攻击）**。

| 机制 | 说明 |
|------|------|
| 魔法门控 | 只有佩戴赛尔玛尼亚宝石的单位/英雄才能拥有法术攻击（§7.3） |
| 宝石骑士 | 佩戴宝石并接受训练的战士，按宝石颜色分级，与稀有度颜色一一对应 |
| 分级命名 | 白色=星骑士 / 绿色=月骑士 / 蓝色=日骑士 / 紫色=光辉骑士 / 红色=圣辉骑士 |
| 敌人持宝 | 天灵帝国同样以宝石驱动法术，敌我共用同一力量规则 |
| 稀有度联动 | 宝石颜色 ↔ 单位/将领稀有度（白/绿/蓝/紫/红），颜色即强度与稀有度标识 |

> 💡 星→月→日→光辉→圣辉，越高级越稀有越强；只有持宝者能施法，法术因此天然"高贵稀有"。

### 5.5 派系数据结构（预留）

每个派系定义为：

| 字段 | 说明 |
|------|------|
| 名称 | 派系名 |
| 兵种池 | 该派系的基础兵种 + 精英兵种列表 |
| 被动加成 | 全局效果（如：所有前排 +15% 血量） |
| 特殊牌型效果 | 打出特定牌型时的额外增益 |
| 专属英雄 | 该派系可选的英雄（1-N 个） |

### 5.6 派系编辑器（开发工具）

**需求**：不硬编码派系逻辑，提供可视化编辑器，方便添加/调整派系。

**技术方案**（初步）：
- Unity ScriptableObject 存储派系配置数据
- Inspector 面板可视化编辑属性
- 新增派系只需创建新的 ScriptableObject 资产，无需改代码
- 开发早期先做 1-2 个派系跑通流程，编辑器工具后续迭代

## 6. 英雄系统 🆕

### 6.1 定位

英雄是棋盘上**最强单位**——直接参战，不占槽，不可阵亡（但会受伤）。

> 📌 **英雄池**：与将领池（§4.4）**分离**。v1 英雄 = **叶斌云**（帝国太子）；后续英雄以张总设定进度为准——小说已写的直接用，未写到的可游戏先行。

| 特性 | 说明 |
|------|------|
| 参战方式 | 站在棋盘后方，像超级棋子一样战斗 |
| 存活机制 | **不可阵亡**。HP 归零时触发受伤存活逻辑（50% HP，参照 §3.4.1） |
| 攻击 | 英雄有自己的攻击力/攻速，普通攻击像普通棋子一样输出 |
| 技能 | 主动 + 被动，最多占用 **4 个槽位** |

### 6.2 技能系统

英雄拥有两类技能，随等级解锁、自主选择搭配。

#### 6.2.1 主动技能

战斗中自动触发，是玩家观战时的主要视觉反馈点。

| 触发方式 | 说明 | 参照 |
|----------|------|------|
| 定时释放 | 每隔 N 秒自动释放一次 | — |
| 攻击计数 | 每攻击 N 次后释放 | 金铲铲 |

> 💡 不同技能可用不同触发方式。如 AOE 技能适合攻击计数，治疗技能适合定时。

**示例**（非最终）：

| 技能 | 类型 | 触发 | 效果 |
|------|------|------|------|
| 旋风斩 | 主动 | 攻击 5 次 | 对前方扇形区域造成 AOE 伤害 |
| 圣光治愈 | 主动 | 每 15 秒 | 治疗全队最低血量棋子 |
| 全军突击 | 主动 | 每 20 秒 | 全队全攻+50% 持续 5 秒 |
| 冰霜陷阱 | 主动 | 每 12 秒 | 在敌方半场放置减速区域 |

#### 6.2.2 被动技能

常驻生效，影响构筑或战斗。

| 类别 | 效果类型 | 示例 |
|------|----------|------|
| 全局 Buff | 对所有棋子生效 | "所有近战棋子护甲+3" |
| 构筑辅助 | 影响牌堆/抽牌/弃牌 | "每关开始额外多抽 1 张牌" |
| 经济管理 | 影响金币 | "利息上限 +2" |
| 将领增强 | 增强将领槽 | "将领槽 +1" |

#### 6.2.3 槽位与选择

| 参数 | 值 |
|------|-----|
| 技能槽总数 | 最多 **4 个**（主动+被动共用） |
| 解锁方式 | 随英雄等级逐步解锁 |
| 选择自由度 | 玩家可全主动、全被动、或混合搭配 |
| 英雄自身被动 | 1 个固定槽，不计入 4 个槽位 |

> 💡 4 个槽位产生构筑广度：全被动 = 稳定军队强化流，全主动 = 靠技能翻盘流。

### 6.3 成长路径

| 阶段 | 内容 |
|------|------|
| 开局 | 选定英雄，默认拥有 1 个被动 + 1 个主动（或 2 选 1） |
| 升级 | 随关卡推进获得经验，达到等级阈值解锁新技能槽 |
| 商店 | 可购买技能升级（强化已有技能效果），或购买新技能替换旧技能 |
| 装备 | 商店购买的装备占用装备槽（§4.4），与技能槽独立 |

| 问题 | 状态 |
|------|------|
| 英雄攻��力和攻速基准 | 待数值设计 |
| 技能池深度（每个英雄有几个可选技能？） | 待内容设计 |
| 技能替换的代价（已学的技能能不能换？花金币重置？） | 待讨论 |

## 7. 棋盘与战斗机制

### 7.1 布局（定稿）✅

| 参数 | 值 |
|------|-----|
| 部署方式 | **RTS 自由部署**，无固定格子，单位在己方半场任意摆放 |
| 部署上限 | **固定 36**（含英雄 + 将领 + 棋子；第一版不做成长，待实际效果再定） |
| 半场划分 | 左右半场对称，纵向开放 |
| 边界 | 单位不可出界、不可被推出半场 |
| 前排/后排 | 由玩家自行摆放决定，不做硬性划分 |

### 7.2 阵型与站位（混合部署模式）✅

**核心原则**：模板自动摆放为默认，手动微调始终可用。

#### 7.2.1 自动入位

- 新棋子按**站位标签**自动落入对应区域空位：前排肉盾 → 前排、中排近战 → 中排、后排远程 → 后排、将领 → 将领区
- 英雄：**专属后排区**（固定区域，不移动、不可移出）
- 满员后新棋子进入支援区（§3.4.4）

#### 7.2.2 预设模板

- 2-3 个预设阵型：**标准阵**（肉盾前/输出中/远程后）、**龟缩阵**（后排收拢）、**突击阵**（前排前压）
- 一键切换，切换后仍可手动微调
- 支持保存**自定义阵型**，下回合增量入位沿用
- 保留**完全手动模式**开关（关闭自动入位）

#### 7.2.3 RTS 式布阵交互（仅布阵阶段，战斗仍全自动）

| 操作 | 效果 |
|------|------|
| 左键拖空白 | 框选多个单位 |
| 左键单击空白 | 取消选择 |
| 左键单击单位 | 单选，显示属性/状态 |
| 双击单位 | 全选同类单位 |
| Shift+左键 | 追加/减选 |
| 右键单击（无拖动） | 整组前往目标点（保持相对阵型） |
| Shift+右键按住 | 线列落子：锚点 = 线列中心基准 |
| Shift+右键拖动 | 方向固定水平；光标水平距离决定线列半长（间距随长度自动缩放），垂直位置决定行位 |
| 松开右键 | 线列落子确认 |
| 拖动中 Esc | 取消本次线列 |
| Ctrl+A | 全选场上单位 |

**线列折行规则**：单行放不下 → 自动折成两行（第二行排在第一行正后方，间距同普通单位间距）；两行仍溢出 → 继续折行直至放完；半场纵向深度仍不足时压缩间距兜底。英雄在选中组时落点受专属区钳制。

- 出牌阶段不限制时长（单机，不催玩家）
- 棋子留存跨回合，阵型可在每回合开始前重新调整

### 7.3 战斗规则

**伤害公式**（百分比减免，参照 LoL 护甲机制）：

```
物理伤害 = 物攻 × 100 / (100 + 护甲)
法术伤害 = 魔攻 × 100 / (100 + 魔抗)
```

- 减伤百分比 = 防御值 / (防御值 + 100)：50 防御 ≈ 33.3% 减伤，100 防御 = 50% 减伤
- 防御再高也无法免疫伤害（减伤趋近 100% 但到不了），不会出现纯减法的“1 点保底”断崖
- 每点防御 = +1% 有效生命（线性增长），与“Buff 线性叠加只加不乘”规则同构
- 防御为负的极端情况第一版钳制为 0；穿透/真实伤害类机制不进第一版（玻璃牌一次性爆发另议，§3.5）

**棋子属性集（8 个）**：

| 属性 | 缩写 | 说明 |
|------|------|------|
| 生命值 | HP | 归零即阵亡 |
| 物理攻击 | ATK-P | 单次物理攻击伤害（减护甲前） |
| 法术攻击 | ATK-M | 单次法术攻击伤害（减魔抗前） |
| 护甲 | DEF-P | 减免物理伤害量 |
| 魔抗 | DEF-M | 减免法术伤害量 |
| 攻速 | SPD | 每秒攻击次数 |
| 射程 | RNG | 1=近战, 2=中程, 3=远程 |
| 移速 | MOV | 棋盘格子/秒，决定接敌速度 |

> 🚧 具体兵种属性数值模板留待后续设计。属性结构先定，内容后填。

**攻击类型**：

- 每个单位有单一主攻击类型：物理 / 法术 / 混合；混合是少数例外（如英雄普攻物理 + 技能法术）
- 大部分单位物理；法术单位中世纪稀有——数量少、获取贵、单体战力强
- 攻击类 Buff 需指明物攻 / 魔攻 / 全攻

**弹道与命中**：

- 核心模型：打偏 = 目标在弹道飞行时间内位移超过命中窗口；命中率是可预测的空间问题，不是概率骰子
- 三类弹道：
  - 直线快弹（弩手/标枪）：预判射击，快准单体
  - 弧线慢弹（弓箭手/投石）：打落点，可越前排、可溅射
  - 法术（法师）：必中锁定、吃魔抗，代价 = 施法前摇可打断 + 法力资源
- 前排"拖住"价值：目标位移趋近于零 → 我方远程命中率稳定
- 🚧 护盾/反制扩展、弹速/命中窗口参数留数值设计

**UI 需求**：

- 目标标记：显示当前锁定目标，让索敌、嘲讽、优先级选择可见
- 弹道预告线：出手前展示弹道轨迹与落点，让"看得见的命中/打偏"成立

**战斗流程**：

- 自走棋式自动战斗，玩家不可干预

**战斗 AI 规则**：

| 规则 | 说明 |
|------|------|
| 默认索敌 | 优先攻击射程内**最近的敌方棋子** |
| 移动逻辑 | 向最近敌方棋子移动，进入射程后停止并开始攻击 |
| 目标切换 | 当前目标阵亡后，重新选择最近的存活敌方棋子 |
| 特殊索敌 | ✅ 三类例外：① 嘲讽/强制目标（前排拉仇恨）② 目标优先级（残血/后排/施法者）③ 法术锁定（施法者选目标） |

**英雄站位**：

| 规则 | 说明 |
|------|------|
| 位置 | 固定站在己方半场后排，不移动 |
| 攻击 | 按自身攻击力+攻速攻击射程内最近敌方棋子 |
| 技能 | 主动技能触发独立于普通攻击（§6.2.1） |

**战斗结束条件（任一触发即结束）**：

| 条件 | 说明 |
|------|------|
| 一方全灭 | 棋盘上无存活棋子 |
| 绝对时限 | 战斗开始后 **180 秒**（防止卡死） |
| 静默结束 | 双方不再产生伤害后 **10 秒** |

## 8. 商店系统（构筑核心）

### 8.1 出现时机

每回合战斗结束后进入商店。

### 8.2 商品类型

| 类型 | 说明 | 影响线 |
|------|------|--------|
| 将领 | 雇佣将领兵种，上场提供全局 Buff + 战斗（占用将领槽）| Buff 线 §4.4 |
| 牌堆操作 | 买牌 / 删牌 / 升级牌面，改变牌堆构成 | 卡牌线 |
| 装备 | 英雄装备，提供被动 Buff（占用装备槽）| Buff 线 §4.4 |
| 特殊属性牌 | 购买已附魔的特殊牌（§3.5），或提供附魔服务 | 卡牌线 §3.5 |
| 直接 Buff | 一次性强化，不占槽，即时全局生效（如全体护甲+1）| 单位线 |
| 特殊单位 | 一次性雇佣兵/魔兽等，仅战斗不占槽 | 单位线 |
| 刷新 | 花钱刷新商品列表 | — |

### 8.3 构筑哲学

- 同样的金币，不同花法导致不同阵容
- 买牌 → 扩充棋子池 → 更容易凑牌型 → 更多特殊单位
- 买道具 → 强化现有阵容 → 即时战力提升
- 买特殊单位 → 直接获得超模棋子 → 短期爆发
- 刷新 → 找关键牌/道具 → 高风险高回报
- **商店就是路线选择**

## 9. 经济系统 🆕

> ⚠️ 这是 PvE 闯关游戏，败一次即终局。无"连胜/连败"概念。

### 9.1 核心机制：利息

| 7 | 结算阶段 Buff | 被动收益 | 每回合结束（如果持有相关 Buff） |

> 🚧 各项具体数值留待平衡性设计。BS 阶段先确定机制存在。

### 9.3 金币用途

## 10. PvE 关卡设计

### 10.1 关卡结构

| 参数 | 值 |
|------|-----|
| 总关数 | **无上限** |
| 每关结构 | **统一 3 回合**，最后一回合打关底 Boss |
| 难度曲线 | **指数增长** |
| 难度节点 | 关 4、关 8 **难度陡增**（具体机制待设计） |
| 商店频率 | **每回合结束后**（§8.1） |
| 难度层级 | 🚧 参照小丑牌，逐级解锁更高难度——不仅数值提升还附带玩法限制（详见 §2.4.2） |

### 10.2 敌人设计

**模式**：C —— 预设脚本模板 + 随机变量混合。敌人不抽牌不出牌（非镜像玩家），但配置随关卡动态变化。

**敌人 IP**（叶历 55 年背景）：主线敌人为**天灵帝国**——通过大量赛尔玛尼亚宝石驱动法术与军队的军事帝国；另有**天神势力**卷土重来（神界回收线）作为并行威胁。敌人同样遵循"持宝石才能施法"规则（§5.4）。

#### 10.2.1 每关三回合结构

```
回合 1：普通兵种组合（随机从同阵营兵种池抽取）
回合 2：+ 精英兵种 + 若干 Buff（从 Buff 池随机）
回合 3：+ 英雄 + 更多 Buff + 对玩家的 Debuff 条件
```

| 回合 | 敌方组成 | 难度定位 |
|------|----------|----------|
| R1 | 纯普通兵种 | 热身——测试你的军队基本功 |
| R2 | 普通 + 精英兵种 + 随机 Buff | 压力上升——敌方开始有协同 |
| R3 | 全部 + 英雄 + 多个 Buff + 玩家 Debuff | Boss 战——敌方火力全开，玩家受限 |

#### 10.2.2 敌人拥有的系统

| 系统 | 敌方是否拥有 | 说明 |
|------|------------|------|
| 将领 | ❌ 不单独上场（英雄替代了此角色） | 敌方英雄 = 将领导位 |
| 装备/Buff | ✅ 有——等同于敌方全局被动 | 随机分配，作为难度杠杆 |
| 特殊属性牌 | ❌ | 玩家专属机制 |
| 利息/经济 | ❌ | 敌方不需要 |
| 棋子留存 | ❌ 不跨关留存 | 每关开始重新配置 |
| 受伤存活 | ❌ | 玩家专属机制 |
| 英雄 | ✅ 有（仅 R3） | 带有 1-2 个技能 |

#### 10.2.3 随机变量

每个回合的敌人配置 = 固定模板 + 随机抽取：

| 变量 | 抽取范围 |
|------|----------|
| 兵种 | 从该阵营的基础/精英/传奇兵种池抽取 N 个 |
| Buff | 从 Buff 池随机 1-3 个 |
| Debuff | 从玩家 Debuff 池随机 1 个（仅 R3） |

> 💡 模板确保每关体验可控，随机确保重玩不重复。

#### 10.2.4 难度增长的体现
