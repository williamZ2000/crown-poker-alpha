# 派系兵种设计（映射表）

> 创建：2026-08-13 ｜ 更新：2026-08-14（#D24 帝国职能网格定稿）
> 规则基准：design.md §3.1（点数档位）、§3.2（牌型→兵种映射 #D18）
> 用途：按派系填充各家族 × 档位的具体兵种。**兵种类型按派系区分，不跨派系预设。**

## 1. 结构骨架（跨派系通用）

| 家族 | 数量规则 | 定位 | 强度上限约束 |
|------|----------|------|--------------|
| 单牌 | 1 个 | 基础 | 基础 |
| 对子 / 连对 | 每连 1 个 | 效率手（清牌 + 高效奖励） | 低 |
| 三张 / 连三张 | 每连 1 个 | 效率手 | 低 |
| 顺子 | 指数（基准 5 张 = 1，每 +2 阶翻倍，**数量不封顶**） | 强度手（中期） | **中**——单体强度上限低于炸弹/同花顺 |
| 炸弹 | 指数（基准 4 炸 = 1，每 +2 阶翻倍） | 强度手（后期） | 高 |
| 同花顺 | 指数（基准 5 张 = 1，每 +2 阶翻倍） | 强度手（终极） | 极高 |

- **档位**：数字（2-10）/ 人头（J/Q/K）/ A（加强版数字），最高点数判档（#D18）
- **A = 数字档强化版，定位相同**；人头牌单独设置定位
- **三带二**：3 个三张家族兵 + 2 个对子家族兵 + 小增益 Buff（效果待内容设计）
- **阻尼原则**：强度手的回报增长（每阶 ×1.414）必须低于其凑齐难度增长

## 2. 帝国（v1）兵种职能网格（定稿 #D24）

| 家族 | 数字档 | A档 | 人头档 |
|------|--------|-----|--------|
| 单牌 | 征召民兵（战士） | 征召官（战士强化） | 猎人（射手） |
| 对子 / 连对 | 帝国步兵（坦克） | 帝国队长（坦克强化） | 帝国弩手（射手） |
| 三张 / 连三张 | 帝国重盾（坦克） | 禁卫军士（坦克强化） | 帝国牧师（辅助） |
| 顺子 | 战士 | 战士（强化） | 辅助 |
| 炸弹 | 巨蟒（太子特色） | 巨蟒（强化） | 辅助（驭蛇师） |
| 同花顺 | 重骑兵（战士） | 重骑兵（强化） | 重甲狙击手（射手） |

**分布**：战士 6 / 坦克 4 / 射手 3 / 辅助 3 / 巨蟒（特色）2。**辅助较稀有**（三张人头、顺子人头、炸弹人头三格）。

> 💡 坦克线：对子/连对（结阵枪阵）+ 顺子（铁骑扛线）；战士线：单牌（杂兵）+ 三张/连三张（重装武士）+ 同花顺（重骑兵）

**特色设定**：
- **炸弹 = 太子特色**：叶斌云（v1 英雄）豢养巨蟒（《天瀑》设定）——巨蟒按档位具有不同属性值；人头档 = 驭蛇师（辅助）
- **同花顺 = 帝国特色**：重骑兵（战士）/ 重甲狙击手（射手）

> 🚧 待定细节：炸弹档位分配细节（暂按 数字/A=巨蟒、人头=辅助）；其余家族名称待定（已定：单牌线 征召民兵/征召官/猎人；对子线 帝国步兵/帝国队长/帝国弩手；三张线 帝国重盾/禁卫军士/帝国牧师）；数值模板待定（下一步强度档）
> 帝国背景参考：《天瀑》叶氏帝国（皇家骑士团 / 禁卫 / 皇城守备 / 盘龙阁）；宝石骑士 = 将领池（星/月/日/光辉/圣辉，§5.4，不占兵种表）
