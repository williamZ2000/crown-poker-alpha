# 派系兵种设计（映射表）

> 创建：2026-08-13 ｜ 规则基准：design.md §3.1（点数档位）、§3.2（牌型→兵种映射 #D18）
> 用途：按派系填充各家族 × 档位的具体兵种名称/定位/数值。**兵种类型按派系区分，不跨派系预设。**

## 1. 结构骨架（跨派系通用）

| 家族 | 数量规则 | 定位 | 强度上限约束 |
|------|----------|------|--------------|
| 单牌 | 1 个 | 基础 | 基础 |
| 对子 / 连对 | 每连 1 个 | 效率手（清牌 + 高效奖励） | 低 |
| 三张 / 连三张 | 每连 1 个 | 效率手 | 低 |
| 顺子 | 指数（基准 5 张 = 1，每 +2 阶翻倍，**数量不封顶**） | 强度手（中期） | **中**——单体强度上限低于炸弹/同花顺 |
| 炸弹 | 指数（基准 4 炸 = 1，每 +2 阶翻倍） | 强度手（后期） | 高 |
| 同花顺 | 指数（基准 5 张 = 1，每 +2 阶翻倍） | 强度手（终极） | 极高 |

- **档位**：数字（2-10）/ 人头（J/Q/K）/ A（加强版数字），最高点数判档（#D18）
- **三带二**：3 个三张家族兵 + 2 个对子家族兵 + 小增益 Buff（效果待内容设计）
- **阻尼原则**：强度手的回报增长（每阶 ×1.414）必须低于其凑齐难度增长（13 张基准下成立；26 张时难度变平，靠"顺子不封顶但单体强度受约束 + 后期主追求炸弹/同花顺"兜底）
