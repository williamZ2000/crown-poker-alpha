# 游戏设计文档

## 1. 项目概述

- **项目名称**: 单人扑克牌闯关游戏（crown&poker-alpha）
- **项目目标**:
  - 实现基本的游戏逻辑，包括发牌、出牌、计分等。
  - 设计简洁易懂的用户界面。
  - 提供多种关卡，增加游戏的挑战性和趣味性。
- **游戏背景**: 一个流落边疆的年轻王子，通过不断的战胜敌人，最终从篡位者手里夺回皇位。
- **技术栈**: Unity 2022 + C#

## 2. 游戏玩法

- **游戏类型**: 回合制闯关游戏
- **玩家目标**: 在每个关卡中，玩家需要通过打出特定组合的手牌对敌人进行对战，最终消灭对手。
- **战斗系统**:
  - 玩家和敌人每轮对战，玩家需要打出特定的牌组合，对敌人进行攻击。
- **金币奖励**:
  - 通关后可获得金币奖励。
  - 玩家可以在关卡之间利用金币构筑牌堆，获得增益等。
- **关卡系统**: 关卡难度会逐渐增加。

## 3. 游戏主循环

- **开始游戏**：进入游戏。
- **初始化**：初始化牌堆、玩家属性、关卡状态和角色选择。
- **关卡循环**：关卡循环，直至玩家通关。

  - **重置玩家状态**：重置玩家的状态。
  - **玩家抽牌**：玩家从牌堆中抽牌。
  - **战斗循环**：不断进行战斗，直到玩家或敌人生命值小于等于0。
    - **战斗循环开始**：战斗开始。
    - **玩家换牌**：玩家可以换牌。
    - **玩家出牌**：玩家从手牌中打出一手牌。
    - **玩家出牌判定**：判定玩家出牌是否合法。
    - **攻击结算**：计算对敌人造成的伤害。
    - **玩家胜利判断**：判断敌人是否生命值小于等于0，如果是，则玩家获得胜利，若否，游戏继续。
    - **敌人攻击**：敌人对玩家进行攻击。
    - **玩家失败判断**：判断玩家是否生命值小于等于0，如果是，则玩家失败，游戏结束。如果否，游戏返回战斗循环开始。
  - **对局表现记录**：记录对局表现。
  - **更新关卡进度**：更新关卡进度。
  - **通关判断**：检查是否通关。
  - **金币结算**：结算金币奖励。
  - **重置牌堆状态**：重置牌堆状态至初始状态，本关内用过的牌回到牌堆。
  - **商店系统**：允许玩家购买商品并刷新商店，通过购买商品更新牌堆和玩家状态。
- **结束游戏**：如果玩家生命值小于等于0，游戏失败并结束。如果玩家通关关卡，游戏胜利并结束。

## 4. 游戏流程详细描述

### 4.1 开始游戏

- **开始游戏**：进入游戏，开始游戏。

### 4.2 初始化

- **初始化牌堆**：生成初始化牌堆，牌堆中包含52张普通牌。
- **初始化玩家属性**：生成玩家对象，并初始化玩家状态。重置玩家的生命值，将玩家生命值设定为100。换牌次数为0。金币数量为5。
- **初始化关卡状态**：设置关卡进度为一。
- **角色选择**：玩家选择一名角色，不同的角色带有不同的属性加成。角色选择后 set 玩家的角色属性。
- **初始化商店状态**：

### 4.3 关卡循环

关卡循环直至玩家通关，每关包含以下流程：

#### 4.3.1 战斗系统载入

- **战斗系统载入**：载入战斗系统，按照关卡进度设置敌人的属性。

#### 4.3.2 重置玩家状态

- **重置玩家状态**：将剩余换牌次数（remaining_switch_times）设置为换牌次数上限（switch_times）。

#### 4.3.3 玩家抽牌

- **玩家抽牌**：玩家从牌堆中抽牌，形成手牌。

#### 4.3.4 战斗循环

不断进行战斗，直到玩家或敌人生命值小于等于0。每回合流程如下：

- **战斗循环开始**：战斗开始。
- **玩家换牌**：玩家可以将手中的牌进行换牌，将选中的牌和牌堆中的牌进行换牌，每次一张。
- **玩家出牌**：玩家从手牌中打出一手牌，手牌根据出牌规则转换为攻击伤害。
- **玩家出牌判定**：判定玩家出牌是否合法。如合法，则进行攻击结算。如不合法则无法出牌，不进行结算。
- **攻击结算**：输出攻击伤害数据，计算对敌人造成的伤害，设置敌人血量。
- **玩家胜利判断**：判断敌人是否生命值小于等于0。如果是，则玩家获得胜利，跳出战斗循环。若否，游戏继续。
- **敌人攻击**：敌人对玩家进行攻击，对玩家造成伤害。
- **玩家失败判断**：判断玩家是否生命值小于等于0。如果是，则玩家失败，游戏结束。若否，游戏返回战斗循环开始。

#### 4.3.5 战斗循环结束后

- **对局表现记录**：记录对局表现，计算剩余手牌数量、出牌次数等。
- **更新关卡进度**：当玩家获得胜利时，关卡进度+1。
- **通关判断**：检查是否通关。
- **金币结算**：根据对局表现记录，结算玩家金币奖励，set 玩家金币数量。
- **重置牌堆状态**：将牌堆状态重置至本关开始时的状态，本关内用过的牌回到牌堆。
- **商店系统**：允许玩家购买商品并刷新商店，通过购买商品更新牌堆和玩家状态。完成购买后进入下一关卡。

### 4.4 商店系统

商店系统是一个单独的界面，在每个关卡战斗结束后出现，当完成购买后进入下一关卡。

- **商品展示**：显示商品列表，包括商品图标、名称、价格、描述等。一次最多展示 cargo_appearing_count 个商品。如果全部购买完后，可以选择花钱刷新商店。
- **商品购买**：玩家选择商品，根据商品价格扣除金币，并执行商品的购买效果。
- **刷新商店**：玩家选择刷新商店，花费金币，并将商品补充至 cargo_appearing_count 个。
- **完成购买**：当完成购买后进入下一关卡。

### 4.5 结束游戏

- **游戏失败**：如果玩家生命值小于等于0，游戏失败并结束。
- **游戏胜利**：如果玩家通关所有关卡，游戏胜利并结束。

## 5. 规则

### 5.1 牌型规则

- **普通牌结构**：标准扑克牌牌型，包含花色和点数。两种属性，花色四种（红桃、黑桃、梅花、方块）；点数13个（A, 2, 3, ..., 10, J, Q, K）
- **特殊牌结构**：v1 版本暂时没有任何特殊牌。
- **出牌规则**：玩家只能打出符合"合法规则"的手牌。
- **合法规则**：
  - 单牌：出牌张数为1。
  - 对子：出牌张数为2，且两张牌点数相同。
  - 三张：出牌张数为3，且三张牌点数相同。
  - 顺子：出牌张数大于等于5，最多12张（即从2开始到A结束），且出牌点数连续。A可做1（A2345），也可作14（10JQKA）。
  - 三带二：出牌张数为三张和一个对子的组合。且三张和对子的点数不同。
  - 连对：出牌由连续点数的对子组成。出牌需要三个对子及以上。连对中对于A的使用定义与顺子相同。
  - 炸弹：出牌张数大于等于4，且每张牌点数相同。（由于允许构筑牌堆，因此牌堆中可能出现超过4张以上的相同牌。）
  - 同花顺：在打出顺子时，同时满足每张牌的花色相同。

### 5.2 伤害计算

- **伤害计算**：玩家对敌人的伤害等于打出的所有牌的点数的和。
- **伤害计算规则**：v1 版本暂用简单累加，后续版本可引入牌型倍率。

## 6. 模块划分

- **卡牌系统**：负责生成和管理卡牌。包括发牌、洗牌、出牌等功能。
- **商店系统**：允许玩家使用金币购买新的卡牌或道具。包括金币管理和商品展示等功能。
- **计分系统**：计算玩家在每局游戏中获得的积分。显示当前积分和通关所需积分。
- **关卡系统**：管理不同的关卡和关卡之间的切换。包括关卡设计、难度调整等功能。
- **角色状态系统**：定义玩家的属性，如生命值、攻击力、防御力等。管理玩家的状态变化，如升级、装备道具等。提供接口供其他系统查询和更新玩家状态。
