# 项目变更日志

## 2026-08-11

- **伤害公式定稿** — 百分比减免（LoL 式）
  - 物理伤害 = 物攻 × 100/(100 + 护甲)；法术伤害 = 魔攻 × 100/(100 + 魔抗)（§7.3）
  - 减伤 = 防御/(防御+100)，防御永不免疫；每点防御 = +1% 有效生命，与线性叠加规则同构
  - 防御为负钳制为 0；穿透/真实伤害类 Buff 不进第一版（玻璃牌另议）
  - 纯减法公式（ATK−DEF）废弃（§2.1.3 同步更新）
  - 关联决策: #D13

- **棋盘与部署定稿** — RTS 自由部署 + 固定 36 + 混合部署
  - 方案 A 转正：RTS 自由部署，左右半场对称、纵向开放，不可出界（§7.1）
  - 部署上限固定 36（含英雄+将领+棋子）；满员后进支援区（§3.4.2）
  - 混合部署：标签自动入位 + 预设模板（标准/龟缩/突击）+ 手动微调（§7.2）
  - 英雄专属后排区；支援区容量 36、按类型自动增援（§3.4.4）
  - RTS 式布阵交互：框选/右键移动/Shift+右键线列（溢出折行），仅布阵阶段生效（§7.2.3）
  - 关联决策: #D14

- **将领体系定稿** — 五档稀有度 + 五类定位
  - 稀有度按颜色命名：白/绿/蓝/紫/红，获取难度递增（§4.4.2）
  - 定位五类：坦克/战士/火力/支援/统御；所有将领参战+被动 Buff，定位是特长倾向（§4.4.2）
  - 定位与稀有度解耦；全红可行但不必然最优
  - 多定位将领留待内容设计
  - 关联决策: #D15

- **派系 IP 定稿（M0-03h 完成）** — 帝国 v1 + 天瀑世界观 + 宝石魔法体系
  - v1 单派系：叶氏帝国开局；多派系后续扩展
  - 背景：叶历 55 年，天灵帝国 + 天神卷土重来（并行剧情，进度以张总为准）
  - 敌人：天灵帝国（持宝石军事帝国）+ 天神势力
  - 英雄池与将领池分离；v1 英雄 = 叶斌云
  - 宝石 = 魔法门控：持宝才能施法；宝石骑士星/月/日/光辉/圣辉（白绿蓝紫红）
  - 具体兵种设计推迟至扑克牌型难度研究之后
  - 关联决策: #D16

- **牌型调整** — 删除同花
  - 同花 13 张手牌出现率 65%，不配作特殊牌型，整行删除（§2.1.2/§3.2）
  - 花色不再召唤精英兵种；花色收益保留（打偏好花色额外收益，§3.3.1）
  - 精英兵种来源改为顺子/炸弹/连对等，具体映射后续定
  - 同花顺保留（终极单位）
  - 关联决策: #D17

- **牌型→兵种映射定稿** — 6 家族 × 3 档
  - 6 家族：单牌 / 对子连对 / 三张连三张 / 顺子 / 同花顺 / 炸弹；三张连三张合并，飞机删除（§3.2）
  - 3 档：数字（2-10）/ 人头（JQK）/ A（加强版数字）；最高点数判档（§3.1）
  - 基础线每张 1 个；特殊线指数公式（基准 1 个，每 +2 阶翻倍，同花顺13=16）（§3.2）
  - 三带二保留：3 重装 + 2 结阵 + 小 Buff
  - 概率衰减拟合入库：docs/research/
  - 关联决策: #D18

- **构筑系统定稿** — 槽位数 + Buff 线性叠加规则 + 玻璃牌重定义

  - 玻璃牌重定义：扑克牌对象（非棋子），打出后从牌堆永久消失 + 强力效果，具体数值待定（§3.5）
