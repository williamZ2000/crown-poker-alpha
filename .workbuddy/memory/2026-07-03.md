# 2026-07-03 工作日志

## M0-03 游戏设计文档讨论（进行中）

### 新确定的要点
- **点数 → 兵种线**：小点数（2-5）前排肉盾，中点数（6-9）均衡，大点数（10-A）后排远程
- **牌型 → 特殊兵种**：顺子=骑兵、同花=精英、炸弹=超模单位、同花顺=终极单位
- **花色不直接对应职业定位**，避免随机性过强；花色用于牌型判定和派系叙事
- **构筑流派**：玩家通过选牌策略+牌型目标+商店购买决定（物理队/法师队/坦克队/精英队/机制流）
- **派系阵营系统**：开局选派系，决定兵种池和构筑方向
- **派系编辑器需求**：Unity ScriptableObject 数据驱动，可视化编辑，不硬编码
