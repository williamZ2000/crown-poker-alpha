## M0-03 游戏设计文档重写（进行中）

### 核心升级方向
- 旧版：简单出牌打伤害
- 新版：卡牌构筑 + 自走棋战斗（参考金铲铲、杀戮尖塔、小丑牌）
- 核心体验：成长构筑流，养军队

### 已确定的设计要素
- 三层循环：回合（抽牌→出棋→战斗）→ 关卡（多回合→商店）→ 整局（英雄成长）
- 卡牌即棋子池，打出去就变成棋盘上的棋子
- 棋盘 4×N 半场，预设阵型模板 + 手动调整
- 英雄：开局选一全程带，主动技能 + 被动加成 + 独立成长
- 商店即路线选择：同样金币不同花法决定构筑方向
- PvE 闯关，线性难度递增

### 待讨论
- 棋子羁绊体系（最高优先级，游戏灵魂）
- 棋盘 N 值、手牌上限、回合机制等细节参数
