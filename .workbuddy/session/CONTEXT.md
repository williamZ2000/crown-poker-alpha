| 步骤 | 内容 |
|------|------|
| P-01 | 运行时自举（RuntimeInitializeOnLoadMethod 生成场景/相机/棋盘/事件总线），不依赖编辑器操作 |
| P-02 | 卡牌域：52 张牌堆、抽牌/手牌、牌型判定引擎（6 家族×档位×数量公式，双同花顺后天判定） |
| P-03 | 回合流四阶段状态机 + 出牌交互（点选手牌→判定→召唤色块棋子） |
| P-04 | 战斗引擎：移动/最近索敌/攻击/LoL 伤害公式/血条/180s 时限 |
| P-05 | 经济+商店：金币/利息/5 格货架（将领占位/秘法/单牌/军备券）/购买/1 金出售/刷新 1→2→3→5→8 |
| P-06 | 敌军预算生成（B₀×E）+ 三回合一关 + 胜负终局 |
| P-07 | 可玩性打磨：回合/关卡显示、选中反馈、结算面板 |
